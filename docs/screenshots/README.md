- 06 — фрагмент Terraform-конфигурации сети, подсетей и ВМ.
- 07–08 — ошибки доступности зоны/платформы, объясняющие отличие DB-ВМ от параметров зоны в задании.
- 09 — обе созданные ВМ, их статусы и IP-адреса.
